# ruff-config-silverwind
[![](https://img.shields.io/npm/v/ruff-config-silverwind.svg)](https://www.npmjs.org/package/ruff-config-silverwind) [![](https://packagephobia.com/badge?p=ruff-config-silverwind)](https://packagephobia.com/result?p=ruff-config-silverwind)

> Shared Ruff configuration

## Usage

```sh
pnpm add -D ruff-config-silverwind
```

In `pyproject.toml`:

```toml
[tool.ruff]
extend = "node_modules/ruff-config-silverwind/ruff.toml"
```
